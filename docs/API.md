# Carelink API Reference

Base URL: `http://localhost:8000`

Interactive, always-current docs (Swagger UI) are auto-generated by FastAPI at
**`http://localhost:8000/docs`** — treat those as the source of truth. The request/response
shapes are defined by the Pydantic models in `backend/models.py`.

## Conventions

- **Timestamps** are epoch **milliseconds** everywhere.
- **Errors** return `{ "detail": "<message>" }` (plus a `traceback` field in dev). The frontend
  surfaces `detail` via `errorDetail()` in `frontend/lib/api.ts`.
- SQL lives only in `backend/crud.py`; routes are thin wrappers under `backend/routes/`.

## Health

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/` | Liveness + version |
| GET | `/health` | API + database status |
| GET | `/health/whisper` | whisper.cpp setup check |

## Sessions

| Method | Path | Purpose |
|--------|------|---------|
| POST | `/api/start-session` | Create a session, returns `session_id` |
| POST | `/api/store-session` | Finalize a session (end time, notes, summary) |
| GET | `/api/sessions?limit=&offset=` | List sessions with summary fields (newest first) |
| GET | `/api/session/{session_id}` | Full session detail (audio, transcripts, summary) |
| DELETE | `/api/session/{session_id}` | Delete a session (cascades to related rows) |

## Audio & transcription

| Method | Path | Purpose |
|--------|------|---------|
| POST | `/api/record-audio` | `multipart/form-data` (`audio`, `session_type`, `patient_id`); WebM→WAV→transcript |
| POST | `/api/process-session` | Run AI analysis on a transcript and store the summary |
| POST | `/api/transcribe` | Transcribe an existing audio file (legacy) |
| POST | `/api/summarize` | Summarize a transcript into mood / agitation / suggestions |

## Prompt chains

Three-stage analysis per session type. Each `{type}` is `medication`, `freeform`, or `sundowning`:

| Method | Path | Purpose |
|--------|------|---------|
| POST | `/api/{type}/extract` | Pull structured data from the transcript |
| POST | `/api/{type}/analyze` | Interpret extracted data (tone, agitation, cognition) |
| POST | `/api/{type}/summarize` | Generate the final summary and store it |

## Export

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/api/export/report?from_ts=&to_ts=` | Care-summary **PDF** over an optional epoch-ms range. Returns `application/pdf` as a download; an empty range yields a valid "no sessions" PDF. |
